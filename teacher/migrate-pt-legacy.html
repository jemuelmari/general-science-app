🧹 One-time Migration

⚠️ Run this ONCE only. This marks all existing PT submissions that have no actual file (legacy entries) as isLegacy = true. They will be hidden from the teacher submissions list but kept in the Google Sheet for audit.

What it does:

  1. Pulls all PT files from the PTFiles sheet
  2. Finds entries where driveFileId is empty (legacy — filename only, no actual file)
  3. Marks them as isLegacy = true
  4. Legacy entries will be hidden from the submissions list

After running: Students who submitted before this date will need to re-upload their files. New submissions will upload to Google Drive automatically.
