Printable Exam Copies

Print the actual questions of any Quiz, Summative Test or Term Exam — for students who can't access the internet. Use Save as Word if you want to edit the paper first.

Tips: Set A / Set B use the same question order students get online (ACADEMIC A → Set A, ACADEMIC B → Set B), so the paper and online results can be checked with the same key. In the print dialog, turn off “Headers and footers” for a clean page. Performance Tasks are not included — they have no test questions.
