# General Science App — Update 2026-11-14

Backend **Code.gs v1.11.0** · config **v1.1.0** · Content sample: **Term 1 Week 1** and **Term 1 Quiz 1 (rev2)**

## How to deploy (do these in order)

1. **Backend (Google Apps Script)**
   1. Open the Apps Script project → replace all of `Code.gs` with `backend/google-apps-script/Code.gs`.
   2. *(Only if Term 1 PT1 was already submitted by students)* set `PT1_FIX_CUTOFF` in **both**
      `Code.gs` (CONFIG) and `config.js` to the date/time when **Term 2 PT1** was really opened,
      e.g. `'2026-11-20T00:00:00+08:00'`. If Term 2 PT1 has not been opened yet, use today's date.
   3. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy.**
      Keep the same deployment so the URL in `config.js` does not change.
   4. If you set `PT1_FIX_CUTOFF`: in the editor, choose `fixTerm1PT1` → **Run** once.
2. **Website (GitHub)** — upload / push every file of this folder.
   These old files were **deleted** and should be removed from the repo too:
   `ssets/` (typo folder), `assets/js/item-analysis-engine.js`, `assets/css/item-analysis-engine.js`,
   `.github/workflows/revert-exams.yml`.
3. **Teachers:** log out and log in again once (teacher pages now always send the teacher token).

## What changed

### Grading
- Transmutation: raw 70 → 75 … raw 100 → 100 (linear), below 70 = raw + 5. The old table gave raw 77–80 a *lower* grade than raw 76.
- Passing raw score is **70%** everywhere (`CONFIG.PASSING_PERCENT`): quiz/ST/TE lock, activities, evidence.
- One grade formula (`Transmutation.computeTermGrade`) and one data source (`TeacherCloud`) for Class Record, Grading Sheet, Reports, Assessment Tracker and Intervention. PT grades now appear in all of them.
- **Score Entry (new page `teacher/score-entry.html`)**: type paper-and-pen scores (quiz, ST, TE, PT). They are marked **P / PAPER**, replace the online score (may be lower) and can be removed. Paste-many-scores supported.
- Print Exam: new **Answer sheet** (bubble sheet) — alone, with the test, or with test + key.
- Sync Center "Apply" / "Import" now save to the cloud gradebook (before: only the teacher's browser).

### Analysis
- **Item Analysis** rewritten: quizzes included, section/set filters, difficulty (p), discrimination (D, upper/lower 27%), distractor counts, retain/revise/reject, per-competency MPS with code + full statement, CSV.
- **Most & Least Learned** (TOS Generator and Class Record) are competency-based from ST1 + ST2, top 5 / top 5 with code + statement. Items are matched by question ID (the old code used the shuffled position → wrong competency).
- **TOS**: 70 % LOTS : 30 % HOTS, balanced so the whole test hits the ratio exactly. Every competency now allows Remembering/Understanding (`data/competencies.json` v1.1.0).

### Assessments (student side)
- Term Exam could be re-taken after passing (score was stored as `te.te`) — fixed.
- Time-up no longer locks a *passing* attempt as "tab-switch / Tampered"; it locks only below 70%.
- Reloading the page no longer restarts the timer or the tab-switch count; answers are resumed. Timer follows the real clock.
- If `randomize.js` cannot load, the test does not start (no more random order that differs from the printed Set A/B).
- **Term 1 PT1 saved as Term 2** — fixed (+ optional migration above).
- Exam Evidence now finds Term Exam records.

### Lessons
- Day 2–4 now carry their own discussion (sample: Term 1 Week 1). Activities: choices shuffled each attempt, no more "A. A)", and **an explanation after every answer**; match pairs show their reason.

### Security & reliability
- Teacher-only backend actions require the teacher token (term access, PT grades, locks, attempts, PT files, overrides…).
- Student names are cleaned on the server and HTML-escaped on every teacher page (a crafted name could steal the teacher password).
- A student device can no longer rename an existing student or change section; Normalize Names (teacher) still can.
- Expired approved retake codes no longer block a new request.
- Row-deleting backend actions run under the script lock.
- Offline queue no longer loses an attempt submitted during a sync; failing items retry every 10 min.
- Service worker installs again and is network-first (students get updated questions/lessons); manifest icons fixed; broken teacher redirects fixed; workflows have write permission; cache-bust runs for any JS/CSS change.
